首次配置「中大课表提取」

只需配置一次。之后在 Safari 分享菜单运行，课表会复制到剪贴板。无需把账号交给本应用。

这是手动配置教程。尚未提供经过 Apple 设备验证的可安装分享链接；真实学校流程仍需 iPhone 验证。
  1. 在 iPhone 打开「快捷指令」，新建快捷指令，命名为「中大课表提取」。
  2. 打开快捷指令详情，开启「在共享表单中显示」，接收类型选择「Safari 网页」。
  3. 添加「在网页上运行 JavaScript」操作，输入选择「快捷指令输入」。将默认脚本全部替换为下方脚本。
  4. 在该操作后添加「拷贝至剪贴板」，内容选择上一步的 JavaScript 结果。再添加「显示提醒」，填写「课表已复制，请回到主屏幕中大课表粘贴」。
  5. 若系统要求允许运行脚本，按系统提示开启；首次运行可能要求允许在学校域名上执行。

每次导入

  1. 用 Safari 打开学校登录，自行完成 NetID 和二次验证。
  2. 登录后打开完整课表页面，选择学期及「全部」周次。若回到登录页，请重新登录；不要在手机单周视图提取。
  3. 点击 Safari「分享」→「中大课表提取」。
  4. 从主屏幕图标打开中大课表 → 导入与设置 → 粘贴课表 → 预览确认保存。

脚本只读取指定课表表格与脱敏学期标题，不读取登录表单或 Cookie。不会自动上传数据。遇到页面改版或加载失败，请使用 Word／PDF 导入。
