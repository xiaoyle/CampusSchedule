首次配置「中大课表提取」

只需配置一次。之后在 Safari 分享菜单运行，课表会复制到剪贴板。无需把账号交给本应用。

本教程按新版 iPhone「快捷指令」界面编写。学校手机课表页没有「全部」按钮也可以使用， 新脚本会在当前登录会话内读取所选学期的完整课表。
  1. 打开 iPhone 的「快捷指令」App。
  2. 点左上角返回，进入「资料库」。
  3. 打开第二行「共享表单」，点右上角「创建」；可长按将其改名为「中大课表」。
  4. 点顶部「接收 App 和其他几个」，保证接收内容包含 Safari 浏览器网页。
  5. 点底部「搜索操作」，搜索并添加「在网页上运行 JavaScript」。
  6. 删除该操作中原有的示例文字，把下方提供的脚本完整粘贴进去。
  7. 继续搜索并添加「拷贝至剪贴板」，输入选择上一项的 JavaScript 结果。
  8. 继续搜索并添加「显示提醒」，填写「课表已复制，回到原地方粘贴课表」。
  9. 保存后，可点右下角运行测试；正式提取时请在 Safari 的课表页从共享表单运行。

每次导入

  1. 用 Safari 打开学校登录，自行完成 NetID 和二次验证。
  2. 登录后打开课表查询页面，选择正确学期并等待任意一周的课程显示完成。手机没有「全部」选项时无需寻找或切换。
  3. 点击 Safari「分享」→「中大课表」。第一次运行时按系统提示允许在该网页执行。
  4. 从主屏幕图标打开中大课表 → 导入与设置 → 粘贴课表 → 预览确认保存。

脚本只在指定课表页面读取学期、课程、周次、教师、地点和节次；不会读取登录表单、 Cookie、姓名或学号，也不会上传数据。手机页面没有「全部」按钮时，脚本会用学校页面 自身的整学期查询方式读取当前学期。遇到学校页面改版或加载失败，请使用 Word／PDF／图片导入。
