# 中大课表助手 v0.4.0 · 网页导入试用版

xiaoyle 制作 · 非中山大学官方应用 · Pre-release

## 下载与使用

下载附件 `CampusSchedule-0.4.0.apk`，安装到 Android 8.0 及以上手机。原有签名一致时可覆盖升级。此包延续开发签名，供小范围试用。

1. 打开“导入与设置”，确认第 1 教学周周一。
2. 点击“从学校网页导入”，自行登录中大本科教务并完成二次验证。
3. 进入“课表查询”，选择学期和“全部”周次。
4. 点击底部“导入当前课表”，核对预览，点击“确认保存”。

学校网页打不开或读取失败时，可继续把电脑导出的 Word / 文字 PDF 保存到手机“下载”文件夹，通过文件导入。导入失败不会覆盖旧课表。

## 新增能力

- 应用内学校网页和底部固定导入按钮。
- 优先获取学校自身导出，无法读取时解析网页表格及合并单元格。
- 保留登录会话，并提供“清除登录状态”；应用不读取登录表单或记录密码、验证码。
- 网页导入复用原有预览、冲突与候选提示、组件刷新和课前提醒。

## 测试范围

学校真实账号登录、二次验证、学校导出服务，以及荣耀/华为安卓真实手机仍待用户验证。自动化解析与模拟器测试仅证明对应逻辑，不能代替学校账号实测；具体结果见仓库 VERIFICATION.md。

课表不会自动同步学校变更，需要重新导入或手动修改。原生鸿蒙通过卓易通运行时仍不具备安卓桌面组件互通能力。

0.4.0 增加网络权限，仅用于学校网页及其引用的认证/验证码等资源。课程与图片仍只保存在本机，不新增后端或云同步。请勿将个人课表或含凭据的截图发到公开 Issue。
