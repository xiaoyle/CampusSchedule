# 中大课表助手 0.14.0 Pre-release

0.14.0 增加邀请制课业社区，供小范围测试公开笔记浏览、发布、收藏、评论和举报。0.13.0 的 Release 性能优化和本机图片课表识别全部保留。

## 安卓端

- 底部增加“社区”，未登录可查看最新帖子并搜索。
- 邀请码注册使用用户名和至少10位密码；登录令牌由 Android Keystore 加密保存。
- 支持最新、收藏、我的发布，以及帖子详情、评论、收藏和举报。
- 灵感笔记阅读页增加“发布”，上传前可修改标题、正文、Markdown状态和标签。
- 社区缓存使用独立 `community.db`，离线时可看到最近缓存；失败操作不会自动重复提交。
- 账号页支持退出当前设备、退出全部设备和注销账号。

## 服务端

- Kotlin/Ktor REST、CloudBase MySQL、Flyway迁移和Dockerfile。
- Argon2id密码哈希，15分钟JWT访问令牌和30天轮换刷新令牌。
- 邀请码事务扣减、帖子乐观锁、收藏唯一键、写操作限流、软删除、举报、封禁和管理审计。
- 提供 OpenAPI、无构建依赖管理页及 CloudBase CLI/控制台部署教程。

## 使用前提

APK 不包含数据库密码、JWT密钥或固定测试服务器。维护者部署 `server/` 后，在 App 社区右上角填写 CloudBase HTTPS 根地址。测试域名仅用于邀请码内测；邮箱验证和找回密码尚未开放。

下载 `CampusSchedule-0.14.0.apk` 可覆盖0.13.0。社区是新增独立数据区，不修改已有课表、任务、笔记或个性化数据。
