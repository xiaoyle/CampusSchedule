# 中大课表助手 0.13.0

本版重点处理首页滑动卡顿，并增加完全在手机本机运行的图片课表识别。

## 更新内容

- 安装包改为不可调试的 Release 构建，启用 R8、资源压缩和 Baseline Profile。
- 今日页只订阅预计算后的轻量状态，移除整页 Crossfade；倒计时只刷新对应卡片文字。
- 支持一次选择最多20张 JPG、PNG 或 WebP 图片。
- 可识别完整学期截图、长截图、纸质课表照片和多张手机单周截图。
- OCR 后进入校对页，可修改周次、星期、节次、课程名、教师和地点，也可移除错误项。
- 单周截图只生成识别到的周次；识别或校对失败不会覆盖已有课表。

## 安装

下载 `CampusSchedule-0.13.0.apk`。签名一致时可覆盖 0.12.0，已有课表、任务、笔记和个性化数据会保留。

图片识别步骤：进入“我的 → 课表与提醒／导入与设置”→ 填写第一教学周周一 →“从图片识别课表”→ 选择图片 → 校对 → 生成预览 → 确认保存。

## 隐私与限制

OCR 模型随 APK 提供，图片仅在本机读取和识别，不上传、不复制到应用私有目录。识别质量会受图片清晰度、裁切、拍摄角度和学校页面版式影响，请在保存前核对。真实机型帧耗时与复杂图片识别效果由试用反馈继续验证。
