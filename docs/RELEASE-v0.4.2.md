# 0.4.2 · 手机版课表导入适配试用包

xiaoyle 制作 · 非学校官方应用

用户反馈 0.4.1 已可完成登录，但手机展示的单周课表不属于原有电脑版读取路由。本版在教务网站中点击底部“导入当前课表”时，使用当前 WebView 登录状态打开完整课表页，加载后自动选择“全部”周次并直接读取表格，移除依赖学校文件导出的步骤。

覆盖安装后：从学校网页导入 → 完成登录 → 点击底部“导入当前课表” → 等待打开完整课表与读取 → 核对学期、课程与周次 → 确认保存。

若切换时出现登录页面，完成学校登录后再点导入；加载有超时提示，不自动覆盖旧课表。文件导入继续保留。

此方案的手机实际切换和读取结果仍待用户验证；学校手机版与完整版登录会话是否互通、学校页面未来改版均可能影响结果。0.4.1 可登录的反馈仅代表该用户设备。
