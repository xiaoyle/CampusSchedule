# 中大课表 iPhone PWA 0.6.0-beta.1

这是“中大课表网页版”的首个完整功能测试版，面向 iOS 17 及以上。使用 Safari 访问项目网站并添加到主屏幕后，可作为独立 Web App 使用。

## 本版内容

- “今日、计划、我的”三栏与完整页面返回层级。
- Word、DOCX、文字 PDF、Safari 快捷指令和图片 OCR 导入；任何导入都先预览或校对。
- 周课表、学习月历、自建课程系列、待办、重复规则、自选星期、子任务和空档雷达。
- 笔记栏目、完整阅读与编辑、自动草稿、安全 Markdown 和精细纸张外观。
- 倒计时专注、学习记录、内置成就、自定义成就、头像、校园资料、主题和启动充能页。
- Apple 日历 ICS、可选匿名加密 Web Push、完整备份与恢复、离线启动和更新提示。

## 已验证

- 生产构建通过，Service Worker 和 Manifest 已生成。
- 11 项核心测试通过，包括 29 项课程、17 周、重复任务、ICS 和图片坐标解析。
- 浏览器自动检查通过：课表导入、待办持久化、离线重开、320/390/768/1280 像素布局及页面错误检查。
- 严格界面审计为 0 项错误、0 项警告。

## 待真机验证

- iPhone 添加到主屏幕后的独立启动和安全区域。
- 中文 OCR 在大图、长图和多图情况下的内存表现与识别精度。
- Safari 快捷指令在真实中大教务课表页面的提取结果。
- Apple 日历导入和主屏幕 Web Push 的授权、送达与点击深链。

本版为 beta。PWA 无法提供原生 iPhone 桌面组件、持续闹铃或可靠的后台环境音。
