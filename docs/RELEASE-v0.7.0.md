# 中大课表助手 0.7.0

本版将课程与课业任务整合为“智能学习日历”，适合每天查看和持续记录。

- 课表页支持周课表与学习月历切换，月历下方统一显示当天课程和截止任务。
- 待办支持每日、每周和自选星期重复，每次任务独立完成、修改、删除和提醒。
- 增加检查清单、拖动排序、任务搜索和类型、优先级、课程筛选。
- 今日页增加下一步建议及未来七天负荷；个人中心增加每周目标、完成率和连续进展。
- 学习看板显示今日任务和周目标，并可直接完成最近一次任务。
- 课程和待办的日期、时间可以通过系统选择器填写。

保持原包名、Room 数据库版本和当前签名，可覆盖安装 0.6.0。旧课表、单次待办、头像、主题、启动动画和组件 DIY 均通过默认字段继续读取。

按试用交付要求，本版仅执行核心逻辑测试、编译、版本、组件声明和签名检查。学习月历布局、重复任务交互、通知到达与真机组件效果由用户安装反馈。
