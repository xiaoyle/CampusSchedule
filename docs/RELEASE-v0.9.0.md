# 中大课表助手 0.9.0

0.9.0 让“自建课程”从一次记录升级为可管理的每周课程系列，并全面重做启动视觉。安装包保持原包名、Room 数据库和既有签名，可覆盖 0.8.0；旧课表、任务、专注记录、成就、头像、主题和桌面 DIY 会继续读取。

## 新增内容

- 添加课程时可选择“仅这一次”或“每周重复”，总次数为 2–30 次且包含首次。
- 有学校课表时按当前日期到学期末建议次数；没有学校课表时默认 16 次，始终可以手动修改。
- 保存前显示星期、时间、次数和日期范围，并检查所有重复日期的冲突；存在冲突时仍可确认保存。
- 编辑或删除系列中的课程时，可选择“仅本次”“本次及以后”或“整个系列”。删除本次及以后会截断系列，过去安排保持不变。
- 每次安排都有稳定编号，任务和专注仍关联原课程系列；今日页、学习日历、三个桌面组件和课前提醒共用同一展开结果。
- 详情显示“第几次／总次数”，并可复制为新课程；添加页面提供最近 5 个自建课程模板。
- 启动页替换为山海芯核、星轨穹顶、木棉矩阵三套原创离线 WebP，增加轻量景深、光轨和粒子。
- 长按入口升级为半透明六边形未来芯核，包含双环进度、电路点亮和完成反馈。
- 个人中心提供三张场景缩略图和“预览启动效果”；旧版仰望、日月、窗边设置会自动映射。
- 桌面 DIY 的三套内置静态海报同步使用新版视觉；自选照片和减少动态效果继续保留。

## 使用提示

在“计划 → 日历”选择日期后点击添加课程。选择每周重复并设置总次数，核对日期范围与冲突摘要后保存。打开系列中的任意一次，即可选择修改或删除的范围。

在“我的 → 个性化 → 启动充能”选择场景并直接预览。系统关闭动画时，背景保持静态，长按进入操作仍可使用。

## 本次验证范围

执行课程系列核心逻辑测试、一次正式 APK 编译、版本号、三个组件、服务、资源尺寸和 APK 签名检查。未执行模拟器矩阵、多品牌回归和长时间提醒测试；真机流畅度、视觉、组件与提醒由试用反馈继续验证。
