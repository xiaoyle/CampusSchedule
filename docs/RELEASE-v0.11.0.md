# 中大课表助手 0.11.0

**xiaoyle 制作 · 同学试用版**

本版让每项待办都能选择任意提醒日期与时间。应用仍以“提前多少分钟”的稳定偏移保存提醒，因此重复任务的每一次也会在相同提前量触发。设置页新增待办通知即时测试和 1 分钟延时测试，两者使用与真实待办相同的独立通知渠道；未取得准时提醒权限时，系统仍可能延迟触发。

“我的”新增灵感笔记。用户可以创建栏目、保留未分类笔记、置顶常用内容，并在清爽、方格、暖纸三种纸张风格中切换，配合五种点缀色和紧凑列表。笔记只保存在本机，不出现在课表、网页导入、桌面组件或排查信息中。

原先突兀的底部黑色提示条已替换为随当前主题变化的圆角悬浮卡片。成功和错误提示使用不同图标与容器颜色，带“撤销”的操作继续可以直接恢复。

## 安装

下载 `CampusSchedule-0.11.0.apk` 后覆盖安装。包名、数据库和签名保持不变，旧课表、待办、头像、主题、专注、成就与组件设置会继续保留。

## 建议真机检查

1. 新建待办并设置一个几分钟后的自定义提醒时间。
2. 在“我的 → 课表与提醒 → 提醒检查”运行“立即测试待办通知”和“1分钟后测试待办提醒”。
3. 锁屏等待测试；若未收到，检查应用通知、课业待办通知渠道、准时提醒权限和电池优化。
4. 在“我的 → 灵感笔记”新建栏目与笔记，切换纸张风格后重新打开应用确认内容仍存在。

## 本次验证范围

执行旧数据默认字段、任意提醒偏移和提醒上限的核心逻辑检查，完成正式编译、版本号、APK 签名和安装包摘要检查。不同品牌锁屏通知及时性由真机继续验证。
