# 数据与隐私说明

## 笔记与草稿

灵感笔记、栏目、Markdown原文、外观设置和未保存草稿只保存在应用私有空间。草稿不会进入课表导出、排查信息或学校网页。Markdown阅读器不会加载远程图片、执行HTML或JavaScript；只有用户主动点击的 `https://` 链接会交给系统浏览器打开。

0.14.0 增加邀请码社区内测。浏览公开帖子无需登录；注册、发布、收藏、评论和举报需要社区账号。

用户从本地笔记点击“发布”后，应用会先展示独立副本供确认，只向用户配置的社区 HTTPS 服务发送标题、纯文本或 Markdown 正文、标签和公开昵称。栏目编号、笔记外观、草稿、NetID、学号、宿舍、课表、头像和其他本地资料不会上传。本地后续修改不会自动同步，网络失败也不会后台自动重试。

社区用户名、公开昵称、可选邮箱、帖子、评论、收藏和举报保存在 CloudBase MySQL。密码只以 Argon2id 哈希保存；15分钟访问令牌和30天轮换刷新令牌用于自动登录，刷新令牌在手机上由 Android Keystore 加密。账号注销会撤销令牌并隐藏该用户发布内容。0.14.0 尚未开放邮箱验证和找回密码。

中大课表助手由 xiaoyle 制作，是个人课表工具，非学校官方应用。

- 课表文件由用户通过系统文件选择器选择，应用解析课程、周次、时间、教师和地点；不将课表中的学生姓名、学号写入课程数据库。
- 用户主动选择的课表截图或纸质课表照片由随安装包提供的中文 OCR 模型在本机处理，不上传网络、不复制到应用私有目录；识别结束或失败后释放原图。校对确认后只保存结构化课程。
- 自选背景和头像仅处理用户通过系统选择器选中的图片，压缩并移除 EXIF 后保存于应用本机私有目录，不上传图片；不请求访问整个相册。
- 个人中心中的昵称、问候语、NetID、学号和宿舍均为选填并仅存本机。它们不用于网页登录，不进入课表文件、组件文字或排查信息；用户可在个人中心一键清除。
- 课业待办的标题、类型、课程关联、截止时间、重复规则、检查清单、优先级、备注、提醒和完成时间仅保存在本机，不进入课表文件、网页导入或排查信息。任务通知可能按用户设置在系统通知界面显示任务标题、课程和截止状态。
- 笔记栏目、标题、正文、置顶状态和外观设置仅保存在本机，不进入学校网页、课表文件、组件或排查信息。
- 专注目标、计时状态、专注记录、环境音选择、复盘统计、成就条件、解锁记录和自定义徽章仅保存在本机。锁屏计时通知会显示用户填写的专注目标；自选徽章图片会重新编码、移除 EXIF 后存入应用私有目录。
- 环境音为安装包内的程序生成资源，不录音、不读取媒体库。作者联系方式仅作为静态文字和外部链接展示；复制、打开网页或拨号盘均由用户主动操作，应用不会自动发送信息或直接拨号。
- 课程和外观数据仅存本机；无统计分析、广告或课表云同步。网络权限用于学校网页及用户主动访问的社区服务。
- 账号、密码和验证码由用户在学校网页直接提交，应用不读取登录表单，不记录凭据，不向登录页面注入导入脚本，也不提供原生 JavaScript 桥接接口。
- WebView 将学校 Cookie 和网页存储保存在本应用私有空间，可能含学校自身的会话或用户资料。点击“清除登录状态”会清除 Cookie、网页存储、缓存、历史和表单缓存，课程与 DIY 保留。
- 只在用户点击导入并位于课表页时获取导出或表格。原始导出只在内存解析；规范化课程结果使用一次性私有缓存，消费后删除，启动及写入时清理超过 24 小时的残留。学生姓名、学号不进入导入结果。
- 通知、准时提醒与后台播放权限用于用户开启的课前提醒和闹铃；是否授予由用户及系统决定。
- “复制排查信息”由用户主动触发，内容为品牌、型号、系统版本、应用版本和可读取的提醒状态，不含课表、账号或设备唯一标识，不自动发送。
- 卸载或清除应用数据会移除本机保存的数据。移除背景或删除主题收藏不保证立即清理全部历史图片副本。
- GitHub Issue 是公开页面，请勿上传密码、验证码、原始个人课表、学生身份信息或含个人信息的截图。

本说明对应安卓 0.14.0，不涵盖学校及其认证服务、系统文件提供方、GitHub、CloudBase平台自身或其他第三方应用各自的数据处理。

## 网页版补充

`web/` 在浏览器本地解析 Word、PDF 和用户主动粘贴的课表，不把内容上传或放入 URL；课表存于 IndexedDB。快捷指令仅在指定学校课表页读取学期、课程、周次、教师、地点和节次；在 iPhone 单周界面会使用当前学校登录会话调用该课表页自身的整学期查询接口。脚本不读取 Cookie、登录表单、姓名或学号。学校登录发生于 Safari 的真实学校页面。JSON 备份由用户保存，包含课程、教师和地点。GitHub Pages 托管处理正常访问请求。清除网站数据/卸载/系统回收可能丢失本地数据，请保留原文件。

## 0.9.0 数据说明

每周自建课程使用一个本机系列记录保存，包括总次数、从某次开始生效的修订和单次例外。它不会上传，也不会进入学校网页登录。三张未来科技启动背景作为应用离线资源打包；自选照片仍会重新编码、移除 EXIF 并保存在应用私有目录。


## 0.10.0 新增本机数据

待办预计用时、空档推荐结果、启动芯核配色及个人中心轮播风格只在本机计算或保存。12 张内置轮播图随安装包离线提供；空档雷达不上传课程、任务或时间安排，也未增加权限。
## iPhone PWA

网页版的课表、自建课程、任务、笔记、草稿、头像、校园资料、专注记录、成就和设置保存在浏览器 IndexedDB。Word、PDF、图片和快捷指令课表在本机处理，不上传。首次图片识别会从模型分发站点下载 OCR 模型，原始图片不会随请求发送。

用户主动开启 Web Push 时，主屏幕 Web App 会上传匿名设备令牌、浏览器推送订阅、触发时间和 AES-GCM 密文。课程名、地点、待办标题与通知深链在发送前由本机加密；解密密钥只保存在该 Web App 的 IndexedDB。用户可关闭推送并删除服务器上的匿名订阅。

完整备份 V2 可能包含课表、任务、笔记、头像和用户主动填写的校园资料。备份由用户自行保存和传输，请勿公开上传。
