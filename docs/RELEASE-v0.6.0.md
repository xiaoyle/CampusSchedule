# 中大课表助手 0.6.0

本版新增“课业待办”与“学习看板”，把课程、作业、考试和复习计划放到同一套本地时间系统中。

- 主界面调整为今日、课表、待办、设置、我的五栏。
- 待办支持课程关联、类型、优先级、可选截止时间、单次提醒、完成、恢复、复制、删除和撤销。
- 今日首页增加头像问候、教学周进度、课程与任务统计、上课倒计时和最近待办。
- 新增“学习看板”桌面组件，显示最近任务、今日课程数、完成进度、头像及 xiaoyle 制作。
- 任务通知使用独立渠道，可从通知直接查看或完成任务。
- 个人中心增加本周课程、未完成任务和本周完成数量。
- 界面版本号改为读取安装包实际版本，避免升级后显示旧编号。

保持包名、Room 数据库版本和当前签名，可覆盖安装 0.5.1。旧版课表、个人资料、头像、主题和组件 DIY 均保留；新增任务字段带默认值。

按试用交付约定，本版只执行核心任务测试、编译、组件声明和 APK 签名检查。具体机型的通知到达、组件尺寸和交互手感由用户真机反馈。
