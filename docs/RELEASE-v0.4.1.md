# 0.4.1 · 学校登录白屏修复试用包

xiaoyle 制作 · 非学校官方应用

修复认证新窗口配置不完整、转换为 GET 重开、15 秒自动销毁的问题。子窗口正常显示并保留原始提交，支持异步窗口、返回与学校主动关闭窗口。增加返回教务登录、超时/渲染异常恢复和复制网页登录排查信息。

安装 CampusSchedule-0.4.1.apk 覆盖旧版，打开“从学校网页导入”重新登录。若仍白屏，点击“复制排查信息”反馈，并描述出现白屏的步骤。排查内容仅含应用、系统和 WebView 版本、当前域名、分类错误码，不含完整网址、Cookie、账号、密码或验证码。

已修复上述代码缺陷；它是否解决真实学校认证白屏仍待用户验证。没有进行全机型测试。不保证此次已覆盖学校认证的全部兼容问题。
