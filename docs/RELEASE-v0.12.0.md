# 中大课表助手 0.12.0

本版将灵感笔记升级为完整阅读与编辑页面，加入纯文本／Markdown选择、自动草稿恢复和更细的纸张、字体、字号、行距、边距与颜色设置。每篇笔记可以单独覆盖默认外观。

今日页已移除重复的课表和待办展开，未来七天、下一步、空档雷达和专注建议共享同一份后台计算结果；倒计时只刷新对应卡片，首页上下滑动更稳定。

所有笔记、草稿和个性化设置仍只保存在手机本机。社区、账号、收藏和评论未加入本版本。

## 安装

下载 `CampusSchedule-0.12.0.apk` 后安装。签名一致时可覆盖旧版，0.11.0 的课表、任务、笔记和个性化设置会继续保留。

## 建议检查

1. 打开“我的 → 灵感笔记”，新建纯文本和 Markdown 笔记。
2. 编辑后返回，检查保存、放弃和继续编辑；也可关闭应用后检查草稿恢复。
3. 调整全局外观，再为一篇笔记启用单独外观。
4. 在今日页连续上下滑动，观察课程、未来七天和空档雷达。
