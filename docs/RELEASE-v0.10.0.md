# 中大课表助手 0.10.0

**xiaoyle 制作 · 同学试用版**

本版修复系统返回键直接退出，并把三个桌面组件全部纳入 DIY。学习看板会根据尺寸显示 2、3 或 4 项待办，可直接打开或完成。

新增空档雷达：从当前时间扫描到 23:00，课程前后各预留 10 分钟，再按截止状态、优先级和预计用时推荐适合当前空档的任务。确认后可直接开始关联倒计时专注。

启动芯核支持五套配色、自定义主色与光环色、透明度和光效强度。个人中心新增四种风格共 12 张原创离线无人风景图：动漫二次元、末世绝境、科技赛博朋克和温馨风景，每天按北京时间轮换，也可左右滑动。

## 安装

下载 `CampusSchedule-0.10.0.apk` 后覆盖安装。保持包名、数据结构和现有签名，旧课表、待办、头像、主题、专注和成就会继续保留。若系统提示来源未知，请按手机提示允许本次安装。
