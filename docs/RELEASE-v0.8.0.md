# 中大课表助手 0.8.0

0.8.0 将课表、任务与学习投入连接成可持续使用的本地学习助手。安装包保持原包名、数据库和签名，可覆盖 0.7.0；课表、任务、头像、主题和桌面 DIY 会继续读取。

## 新增内容

- 主导航精简为“今日、计划、我的”；计划页统一放置学习日历与待办。
- 今日页新增“开始专注”，支持 25、45、60 分钟、自定义 1–180 分钟倒计时和最长 12 小时正计时。
- 新增校园昼夜光轨专注页、暂停／继续／结束、进程恢复、锁屏计时控制和专注结束处理。
- 内置程序生成的檐下雨声、珠海海浪、静谧图书馆三种环境音，默认关闭并记住音量。
- 新增本周、上周和最近四周学习复盘，以及独立的每周专注目标。
- 新增初光启页、木棉成序、钟楼守约、七日星轨、山海同频五枚原创校园珐琅徽章。
- 成就馆支持进度、解锁庆祝、最多三枚精选徽章、自定义成就和徽章编辑器。
- 自定义条件覆盖累计／单次／连续专注、完成任务、按时完成、本周专注和指定课程专注；徽章支持四种外形、颜色、纹理、边框、24 个图标、短字符和自己的图片。
- “我的”新增作者栏目，提供项目链接、问题反馈、微信复制和打开系统拨号盘。

## 使用提示

从今日页选择目标并开始专注。锁屏控制与环境音依赖系统允许应用显示通知及运行前台媒体服务；厂商省电策略仍可能影响后台行为。少于 10 分钟的记录不计入有效专注和内置成就。

成就数据只根据本机专注记录和任务实例计算，不上传。内置成就解锁后永久保留；已经解锁的自定义成就若修改条件，需要先确认重置。
