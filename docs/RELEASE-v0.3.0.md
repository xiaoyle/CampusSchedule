# 中大课表助手 v0.3.0 · 桌面 DIY 试用版

**xiaoyle 制作** · 非中山大学官方应用

## 下载与安装

在本页 Assets 中下载 **CampusSchedule-0.3.0.apk**，保存到安卓手机后安装。Source code 是源码，不是手机安装包。

安装 → 导入 Word / 文字 PDF 课表 → 检查提醒 → 添加桌面组件。

已有本项目旧版时可尝试直接更新；签名不一致时无法覆盖，请先确认下载来源，不要为解决提示贸然卸载，卸载会删除本机课表和图片。

## 这次新增

- 自选背景图片，支持拖动定位、放大裁剪、模糊、遮罩和背景透明度。
- 照片卡、毛玻璃、课程便签三套外观。
- 自定义标题、短句、课程字号和点缀色。
- 最多收藏 8 套搭配，下一节课与今日课程分别设置。
- 保留 Word / PDF 导入、课程提醒、持续闹铃及 xiaoyle 制作署名。

入口：导入与设置 → 桌面 DIY · 换上自己的照片 → 编辑 → 保存到桌面。

## 适用范围与测试状态

- 最低 Android 8.0；不同启动器、系统字号和后台限制可能影响展示与提醒。
- 此次完成构建、lint、APK 签名及基础安装启动检查；DIY 图片和不同手机效果仍需实际试用反馈。
- 原生 HarmonyOS 5 / 6 / NEXT 通过卓易通运行时，不能因此在鸿蒙桌面获得安卓组件。本包不是原生鸿蒙版，也不是 iPhone 版。
- 学校登录入口关闭；请将电脑导出的文件保存到手机“下载”文件夹后导入。
- 本版本采用开发签名，仅供小范围试用，不代表已完成应用商店审核或全机型验证。
