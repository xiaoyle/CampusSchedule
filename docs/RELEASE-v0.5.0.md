# 中大课表助手 0.5.0

**xiaoyle 制作 · 同学试用版**

本版把课表助手扩展成可个性化的本地校园助手：可在每周课表中添加、编辑和删除指定日期的一次课程；新增个人中心、头像、校园资料、课程颜色、康乐园绿/珠海海蓝/四季主题，以及长按芯片充能启动页。

头像可选择显示在两个桌面组件右下角。桌面 DIY 新增仰望、日月和窗边三套原创静态海报；由于 Android 普通桌面组件限制，视频、GIF 和实况照片不会在组件中连续播放，动态效果只用于 App 启动页。

安装新版后可直接覆盖 0.4.2，原课表、文件导入、学校网页登录、课前通知、持续闹铃和原有组件 DIY 保留。个人资料只存本机，不参与学校登录或排查信息。

本次完成必要编译、核心逻辑、签名和基础启动检查。头像裁剪、不同启动器组件布局、动画流畅度及厂商后台提醒由用户真机继续验证。
